مكتبة Skills للذكاء الاصطناعي بالعربي: مهارات جاهزة لـ Claude وأدوات البرمجة

تجمع هذه المكتبة أشهر الـ Skills (المهارات) المفتوحة المصدر على GitHub في مكان واحد، مصنفة حسب الاستخدام: برمجة، تسويق وSEO، تصميم، مستندات، اختبار وجودة، ذكاء اصطناعي، وغيرها. لكل مهارة شرح عربي مكتوب يدويًا، وتقييم جودة، ورابط تحميل مباشر من مستودعها الأصلي.

كيف تستخدم المكتبة؟

  • ابحث أو اختر تصنيفًا، ثم افتح المهارة لقراءة تفاصيلها وملف SKILL.md بالعربية.
  • اضغط «تحميل» لتحصل على ملف ZIP، أو أضف عدة مهارات إلى الحزمة وحمّلها معًا.
  • ارفع الملف في Claude، أو ضع المجلد في ~/.claude/skills/ إن كنت تستخدم Claude Code.

الأسئلة الشائعة

ما هي الـ Skill؟

مجلد فيه ملف SKILL.md وتعليمات وسكربتات اختيارية، يعلّم المساعد الذكي مهمة محددة (مثل التعامل مع ملفات Word أو كتابة نصوص تسويقية) فيطبقها عند الحاجة.

كيف أضيف skill إلى Claude؟

حمّل ملف ZIP من هنا، ثم من إعدادات Claude افتح Capabilities ثم Skills وارفع الملف. في Claude Code انقل المجلد إلى ~/.claude/skills/ وأعد تشغيل الجلسة.

هل الـ Skills آمنة؟

ليست آمنة تلقائيًا. بعضها يشغّل سكربتات على جهازك. اقرأ الملفات قبل الاستخدام، واختر مصادر موثوقة، وراجع الرخصة.

من أين تأتي البيانات؟

نسحبها يوميًا من مستودعات GitHub العامة. الأوصاف العربية مكتوبة ومراجعة يدويًا، وما لم يُراجَع بعد يظهر بوسم «ترجمة آلية».

هل التحميل من موقعكم؟

لا. الملفات تُحمَّل مباشرة من مستودع المؤلف على GitHub إلى جهازك، وتخضع لرخصته.

المهارات ملك لأصحابها. المكتبة لا تضمن أمان أي مهارة.
