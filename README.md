# monsinfopubilc

ملفات البيانات العامة التي تقرأها صفحات مدونة مونستر للمعلوميات (يتم تحديثها تلقائيا بواسطة GitHub Actions):

- `ai-news/news.json`: أحدث أخبار الذكاء الاصطناعي من خلاصات RSS (كل 3 ساعات).
- `api-cost-calculator/prices.json`: أسعار واجهات الذكاء الاصطناعي (يوميا).
- `github-projects/projects.json` و`details.json`: أهم مشاريع GitHub في الذكاء الاصطناعي (يوميا).

الملفات الخاصة (القوالب وملفات بلوجر) في مستودع منفصل خاص.
