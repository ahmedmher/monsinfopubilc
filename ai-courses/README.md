# كورسات الذكاء الاصطناعي المجانية

- `courses.json`: بيانات الكورسات (العنوان، صورة الغلاف، الدروس). هو الملف الوحيد الذي تعدله.
- `app.js`: التصميم والمنطق (يقرأ `courses.json` تلقائيا).
- `blogger-snippet.html`: الكود الذي يوضع في صفحة بلوجر.
- `index.html`: صفحة تجربة مباشرة على GitHub Pages.

صورة الغلاف: ضع رابطا كاملا في `cover`، أو ارفع الصورة في هذا المجلد واكتب اسمها فقط (مثل `claude.jpg`).
